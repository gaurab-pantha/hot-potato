# Hot Potato

A tiny one-button browser game. Plain HTML, CSS and JS. No frameworks, no libraries, no build step. The three game files (`index.html`, `style.css`, `script.js`) are under 3KB combined.

## How to play

- Tap the potato to start.
- The potato heats up. Its face gets more worried, it starts to sweat, and the room turns red.
- Tap it again to pass it. That resets the heat, and the potato jumps somewhere new.
- Every pass makes the heat build faster, with a random wobble so no two rounds feel the same.
- If the bar fills, it burns. Your best score is saved in the browser.
